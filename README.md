### Demo - https://finance-tracker.tech

## Stack:

### Front
1. React + Vite + TS
2. Tailwind
3. Recharts
4. Zod

### Back
1. Nest + TS
2. Postgres + TypeORM
3. JWT Auth

## Installation
```
git clone https://github.com/Reyrin/finance-tracker.git
```
## Installing dependencies
```
npm install
```
## Starting a project

### Front
```
npm run dev
```

### Back
```
npm run star:dev
```

### Db
```
you also need to run a docker container with postgresql
```

## Building a project
```
npm run build
```
